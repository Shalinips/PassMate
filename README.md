## 💡 The Idea Behind PassMate

</div>

> **"Why search through five WhatsApp groups when your notes can be one click away?"** 

PassMate is a full-stack web application designed to make it easier for students to find and access study materials.

Instead of searching through multiple folders, messages, or groups, students can simply select their:

**Year → Semester → Subject**

and get the available study materials instantly.

The idea is simple:

<div align="center">

### 👨‍🎓 Seniors Share → 📚 Juniors Learn → 🎓 Everyone Wins

🚀 Getting Started
</div>
1️⃣ Clone the repository
git clone https://github.com/Shalinips/PassMate.git
cd PassMate
2️⃣ Start the Backend
cd backend
npm install
node server.js

The backend will run at:

http://localhost:5000
3️⃣ Start the Frontend

Open another terminal:

cd frontend
npm install
npm start

The frontend will run at:

http://localhost:3000
4️⃣ Make sure MongoDB is running

PassMate uses MongoDB for storing note information.

The application connects to:

mongodb://127.0.0.1:27017/passmateDB
